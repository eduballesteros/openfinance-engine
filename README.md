# openfinance-engine

Backend de finanzas personales con integración bancaria (Enable Banking) y chat con IA (Anthropic).

## Puesta en marcha

Requisitos: Java 21 y Docker en ejecución.

1. Copia `.env.example` a `.env` y rellena los valores.
2. Verifica el proyecto con `./mvnw clean verify` (en Windows, `.\mvnw.cmd clean verify`).
